プラグイン本体の表示はポルトガル語です。ガイドだけが複数の言語に
対応しています。プラグインの画面に出る言葉の対応表は「パートC」に
あります。


---------------------------------------------------------------------
 1. TWITCH WORLD とは
---------------------------------------------------------------------
どのTwitchチャンネルのチャットも、Final Fantasy XIV「の中」に
表示できるDalamudプラグインです。希望すれば、ゲームを離れずに
返信も送れます。

チャットの見方は「2通り」あります(同時に使えます):
  * ウィンドウ: 画面上で自由に動かせる小さなプラグインのウィンドウ。
  * ゲームのチャットのタブ: FF14のチャット自体のタブにメッセージが
    表示され、人ごとの色や MOD / VIP のバッジが付きます。

プラグインが「通さない」もの(固定のルール):
  * / または ! で始まるメッセージ(ボットのコマンド)
  * 絵文字、エモート、リンク
  * 同時に2つ以上のチャットへ接続すること


---------------------------------------------------------------------
 2. 始める前に(このリストを確認してください)
---------------------------------------------------------------------
[ ] インターネットに接続された Windows 10 または 11 のPC。
[ ] Final Fantasy XIV がインストール済みで、XIVLauncher から
    Dalamud を有効にして起動している(すでにプラグインを使っている
    方はOKです)。
[ ] XIVLauncher からゲームを少なくとも「1回」起動したことがある。
[ ] Cドライブに約600MBの空きと、5〜15分の時間。
[ ] インストール中(パートA)はゲームを「終了」しておく。

チャットを「読む」だけならTwitchアカウントは「不要」です。
メッセージを「送る」場合のみ必要です。


---------------------------------------------------------------------
 3. 重要な注意
---------------------------------------------------------------------
* Dalamudのプラグインはスクウェア・エニックスの利用規約で許可されて
  いません。このプラグインは文字を読み書きするだけで、ゲームを自動化
  しませんが、プラグイン使用のリスクはあります。自己責任でご利用
  ください。
* Twitchの「トークン」(パートC)は「パスワード」と同じです。誰にも
  見せたり送ったりしないでください。PC内に平文で保存されます。
* このプラグインは非公式で、スクウェア・エニックス、Twitch、Dalamud
  とは無関係です。
* このインストーラーには有料のデジタル署名がありません。そのため
  Windows(や一部のウイルス対策ソフト)が警告することがあります。
  パートAをご覧ください。


---------------------------------------------------------------------
 4. パートA - インストール(PCで、ゲームを終了した状態で)
---------------------------------------------------------------------
  1. ファイル  TwitchWorldFF14-Setup.exe  を「ダブルクリック」します。

  2. 「Windows によって PC が保護されました」という「青い」画面が
     出たら:
        - 「詳細情報」をクリック
        - 表示された「実行」ボタンをクリック
     (有料のデジタル署名が無い新しいプログラムでは必ず表示されます。
     お使いのウイルス対策ソフトがブロックした場合は、このファイルを
     GitHub の公式プロジェクトページ(Releases)から入手した場合だけ許可してください。)

  3. 黒い画面が開きます。使う言語の番号を入力して Enter を押します。
     例: 日本語なら 2 と入力して Enter。

  4. 「続行しますか?」という確認が出ます。「はい」をクリック。

  5. 「待ちます」。黒い画面に [1/6] から [6/6] まで進行状況が
     表示されます。画面を「閉じないで」ください。初回は .NET
     (約250MB)をダウンロードするため、数分かかることがあります。
     止まって見えても、動いているのでそのままお待ちください。

  6. 最後に「完了しました!」というメッセージが出て、次のように
     なります:
        - このガイドがメモ帳で開く
        - デスクトップにショートカットが2つできる:
            「Twitch World FF14」(フォルダーを開く)
            「Twitch World FF14 - ガイド」(このガイドを開く)
        - プラグインの「パス」が自動でコピーされる(パートBでゲーム内に
          貼り付けます)

インストール先のフォルダー:   C:\Twitch World FF14

エラーメッセージが出た場合は、セクション9(よくある問題)を
ご覧ください。


---------------------------------------------------------------------
 5. パートB - ゲーム内でプラグインを有効にする(最初の1回だけ)
---------------------------------------------------------------------
  1. XIVLauncher から Final Fantasy XIV を起動し、キャラクターで
     ログインします。

  2. ゲームのチャット欄に   /xlsettings   と入力して Enter を押します。
     「Dalamud Settings」ウィンドウが開きます。

  3. 左のリストで  「Experimental」  をクリックします。

  4. 下へスクロールして  「Dev Plugin Locations」  を探します。

  5. その欄の空のテキストボックスをクリックし、  Ctrl + V  でパスを
     「貼り付け」ます。次のとおりに表示されるはずです:

        C:\Twitch World FF14\Source\bin\Release\TwitchWorld.dll

     (何も貼り付けられなかった場合は、上のパスを正確に入力して
     ください。)

  6. ボックスの横の  +  ボタンをクリックします。パスがリストに
     追加されます。

  7. 下の  「Save and Close」  をクリックします。

  8. 次に   /xlplugins   と入力して Enter を押します。

  9. 左のメニューで  「Dev Tools」  をクリックし、続けて
     「Installed Dev Plugins」  をクリックします。

 10. 「Twitch World」  を探し、スイッチが「オン」(点灯)になって
     いることを確認します。Twitch World のアイコン、「v1.0.0.0」、
     「by Lirou」が表示されるはずです。

 11. ゲームのチャットで   /tw-chat   と入力します。「Twitch World」
     ウィンドウが開きます。

完了です! プラグインのインストールが終わりました。あとは、どの
チャットを読むかを選ぶだけです。


---------------------------------------------------------------------
 6. パートC - Twitchのチャットに接続する
---------------------------------------------------------------------
プラグインは「まっさら」な状態です: チャンネルもアカウントも未設定です。

プラグインの画面に出る言葉(ポルトガル語です)の対応表:
   Config ......................... 設定
   Conectar / Conectar agora ...... 接続 / 今すぐ接続
   Reconectar ..................... 再接続
   Desconectar .................... 切断
   Só ler as mensagens do chat .... チャットのメッセージを読むだけ
   Ler e também enviar mensagens .. 読むのに加えてメッセージも送る
   Canal reconhecido .............. チャンネルを認識しました
   Conectado a #canal ............. #チャンネル に接続中

  1. 「Twitch World」ウィンドウで  Config  をクリックします。

  2. 「1) Link do chat (ou só o nome do canal)」に、チャンネルを
     入力します。次のどれでも使えます:
        https://www.twitch.tv/チャンネル名
        https://dashboard.twitch.tv/popout/u/チャンネル名/stream-manager/chat
        チャンネル名
     その下に緑色で  「Canal reconhecido: チャンネル名」  と
     表示されます。

  3. 「2) O que você quer fazer?」で、どれか「1つ」を選びます:
        ( ) Só ler as mensagens do chat   (読むだけ)
              -> いちばん簡単。アカウントもトークンも「不要」です。
        ( ) Ler e também enviar mensagens (/tw-chat)   (読む+送る)
              -> 手順4が必要です。

  4. (メッセージを「送る」を選んだ場合のみ)Twitchのトークンを
     入手します:
        a) ブラウザで  https://twitchtokengenerator.com  を開く
           (よく知られたサードパーティのサイトです)。
        b) 「Bot Chat Token」を選ぶ。
        c) 権限  chat:read  と  chat:edit  にチェックを入れ、「あなた
           自身の」Twitchアカウントで承認する。
        d) 「Access Token」(長い文字列)をコピーする。
        e) プラグインに次を入力する:
             「Seu nome de usuário da Twitch」 = あなたのアカウント名
             「Token de acesso」 = コピーしたトークン(Ctrl+V)
     注意: トークンはパスワードと同じです。誰にも見せないでください。

  5. 「Conectar agora」をクリックします。状態が「緑色」になります:
        Conectado a #チャンネル名

  6. (任意)「Conectar automaticamente ao abrir o jogo」にチェック
     (ゲーム起動時に自動接続)。

メッセージは「Twitch World」ウィンドウに表示されます。


---------------------------------------------------------------------
 7. パートD - 使い方: 2通りの方法
---------------------------------------------------------------------

=== 方法1: プラグインのウィンドウで ===
  * /tw-chat(文字なし)と入力すると、ウィンドウが開閉します。
  * ウィンドウは動かせて、角を引っ張ると大きさを変えられます。
  * 「Ler e também enviar」を選んだ場合は、下の入力欄に書いて Enter
    を押します。この場合は /tw-chat と打つ必要は「ありません」。

=== 方法2: ゲームのチャットの中で(タブに表示) ===
ゲームはプラグインが勝手にタブを作ることを許していません。そこで、
自分でタブを作り、そのタブにどのチャットの「チャンネル」を表示するか
を指定します。最初に1回だけ行います:

  1. タブを作る: ゲームのチャットウィンドウでタブの横の  +  ボタンを
     クリックし、名前を  Twitch  にします。

  2. プラグイン側(/tw-chat > Config):
        - 「Mostrar as mensagens no chat do jogo (só você vê)」に
          チェック(ゲームのチャットに表示。見えるのは自分だけ)
        - 「Canal usado no chat do jogo」は  「Linkshell [8]
          (recomendado)」  のままにします。

  3. ゲーム側で、各タブが表示するチャンネルを設定します:
        - Character Configuration > Log Window Settings > Log Filters
          を開きます。(ゲーム内の名前はお使いのゲームの言語で表示
          されます。番号 [8] を目印に探してください。)
        - 「Twitch」タブを選び、サブタブ「Chat」を選びます。
        - 「Linkshell [8]」「だけ」にチェックを入れます(そのタブの
          他はチェックを外す)。
        - 次に「General」タブ(ほか、好きなタブ)を選び、
          「Linkshell [8]」の「チェックを外し」ます。メッセージが
          2か所に表示されないようにするためです。

  4. Twitchタブには次のように表示されます:
        [バッジ] 名前 disse: メッセージ
     見えるのは「あなただけ」です。ゲーム内の他の人には見えません。

  メッセージを「送る」には、ゲームのチャットで次のように入力します:
        /tw-chat メッセージ
  (ヒント: 定型文のマクロを作ると便利です。例: /tw-chat ありがとう!)

色とバッジ(/tw-chat > Config > 「Cores e destaques do chat」):
  * 各ユーザーがTwitchで選んだ色で表示されます。ゲーム内チャットでは
    色が「近い色」になります(ゲームの色数が少ないため)。
  * 名前の前のバッジ: [STREAMER] [MOD] [VIP] [SUB] [BOT]
  * あなたをメンションしたメッセージは「金色」で表示
  * ボット(フォロー通知、レイドなど)のメッセージは青緑色で表示
  * 隠されるメッセージはありません。

   /xlsettings              Dalamudの設定

 9. よくある問題
---------------------------------------------------------------------
- インストーラーに「うまくいきませんでした」と出た:
    1) インターネット接続を確認して、もう一度実行してください。
    2) 解決しない場合は、画面のスクリーンショットと次のファイルを、
       GitHub のプロジェクトページの「Issues」(New issue)に添付してください:
       C:\Twitch World FF14\install-log.txt

- 「Dalamud が見つかりません」と出た: XIVLauncher(Dalamud有効)で
  ゲームを一度起動して終了してから、インストーラーをもう一度実行
  してください。

- 「Installed Dev Plugins」に「Twitch World」が出ない: パートBの
  パスが正しいか、+ と「Save and Close」をクリックしたかを確認し、
  ゲームを一度終了してもう一度起動してください。

- アイコンが「?」になる: プラグインをオフ→オンにするか、ゲームを
  再起動してください。

- 「Canal reconhecido」が出ない: チャンネル名だけを入力してください。

- 状態が緑にならない: 「Conectar」か「Reconectar」をクリックし、
  インターネット接続を確認してください。

- メッセージが見えない: そのチャンネルで実際に誰かが話しているか
  確認してください。

- メッセージが別のタブに出る: 方法2の手順3をやり直してください
  (Linkshell [8] は Twitch タブだけにチェック)。

- 自分のメッセージが送れない: 「Ler e também enviar」を選んだか、
  ユーザー名とトークンが正しいかを確認してください。/ や ! で始まる
  メッセージやリンクは拒否されます。メッセージ間には最低約1.5秒の
  間隔があります。

- ゲームのパッチ後にプラグインが読み込まれない: インストーラーを
  もう一度実行してください(プラグインを再度準備します)。それでも
  だめな場合は、Dalamudが変更された可能性があり、新しいバージョンが
  必要です。


---------------------------------------------------------------------
 10. 更新、設定の削除、アンインストール
---------------------------------------------------------------------
更新 / 再インストール: ゲームを終了してインストーラーをもう一度
実行します。すべてやり直され、設定は「そのまま保持」されます。

別のフォルダー(例: C:\TwitchWorld)に古いバージョンがあった場合:
コピーが2つにならないよう、/xlsettings > Experimental で古いパスを
(ゴミ箱ボタンで)削除して保存してください。

設定(チャンネル、ユーザー名、トークン)を消す: ゲームを終了した状態で、
次のファイルを削除します
   %APPDATA%\XIVLauncher\pluginConfigs\TwitchWorld.json
(このアドレスをエクスプローラーのアドレスバーに貼り付けます)。

アンインストール:
  1. ゲーム内: /xlsettings > Experimental > TwitchWorld.dll のパスを
     (ゴミ箱で)削除 > Save and Close。
  2. ゲームを終了します。
  3. デスクトップのショートカット2つを削除します。
  4. フォルダー  C:\Twitch World FF14  を削除します。
  5. (トークンを使った場合)安全のため、Twitchのサイトの 設定 >
     接続 で、そのアプリのアクセスを取り消してください。
