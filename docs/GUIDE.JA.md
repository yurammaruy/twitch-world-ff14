# Twitch World FF14 · GitHub のリンクでインストール – 完全ガイド

[← README](../README.ja.md)

[English](GUIDE.EN.md) · [Português](GUIDE.PT.md) · **日本語** · [Deutsch](GUIDE.DE.md) · [Français](GUIDE.FR.md)

> インストーラーもダウンロードも .NET も不要です。**1 つのアドレス**を Dalamud に貼り付けるだけで、通常のプラグイン一覧から Twitch World をインストールできます。更新も自動です。XIVLauncher + Dalamud が動く環境(Windows / Linux / macOS)で使えます。

## 始める前に

- XIVLauncher から **Dalamud を有効にして** Final Fantasy XIV を一度以上起動していること(すでにプラグインを使っていれば OK)。
- インターネット接続。
- 以前 `.exe` で Twitch World をインストールした場合は、先に下の**ステップ 0**を行ってください。

## 重要

- Dalamud プラグインはスクウェア・エニックスの利用規約で**許可されていません**。このプラグインは文字の読み書きのみで、ゲーム内の操作を自動化しませんが、リスクはあります。自己責任でご利用ください。
- 非公式プロジェクトです。スクウェア・エニックス、Twitch、Dalamud とは無関係です。
- 「トークン」(パートC)はパスワードと同じです。絶対に他人に見せないでください。
- Dalamud はこれを*サードパーティのリポジトリ*として表示します。これは正常です。ソースコードはこの GitHub プロジェクトで誰でも確認できます。

## ステップ 0 – 以前 .exe を使った場合のみ

1. `/xlsettings` と入力して Enter を押し、**Experimental** をクリックします。
2. **Dev Plugin Locations** の `TwitchWorld.dll` のパスの横にあるゴミ箱アイコンをクリックします。
3. **Save and Close** をクリックし、ゲームを終了してもう一度起動します。
4. (フォルダ `C:\Twitch World FF14` は後で削除して構いません。設定は保持されます。)

## パートA – Dalamud に GitHub のリンクを追加する(最初の1回)

1. ゲームのチャット欄に `/xlsettings` と入力して Enter を押します。*Dalamud Settings* が開きます。
2. 左の一覧で **Experimental** をクリックします。
3. **Custom Plugin Repositories** までスクロールします。
4. 空のテキスト欄をクリックし、次のアドレスを **Ctrl + V** で貼り付けます:

   ```text
   https://raw.githubusercontent.com/yurammaruy/twitch-world-ff14/main/repo.json
   ```

5. 右の **+** ボタンをクリックします。アドレスが一覧に追加されます。
6. アドレスの横の小さな**チェックボックス**がオンになっていることを確認します。
7. 下の **Save and Close** をクリックします。

> ヒント: Ctrl+V で何も貼り付けられない場合は、上のグレーの枠の右上のコピーボタンでもう一度コピーしてください。

## パートB – 一覧からプラグインをインストールする(最初の1回)

1. `/xlplugins` と入力して Enter を押します。プラグインインストーラーが開きます。
2. 左のメニューで **All Plugins** をクリックします。
3. 検索欄に `Twitch World` と入力します。
4. **Install** ボタンをクリックし、数秒待ちます。
5. **Installed Plugins** で **Twitch World** を探し、スイッチがオンになっていることを確認します。アイコン、バージョン、**by Lirou** が表示されるはずです。
6. ゲームのチャットで `/tw-chat` と入力します。「Twitch World」ウィンドウが開きます。

> これでインストール完了です。次に、読み込むチャットを選びます(パートC)。

## Twitch トークンの取得方法

**トークンが必要なのはメッセージを「送信」するときだけです。** チャットを読むだけなら、アカウントもトークンも不要なので、この節は飛ばしてください。トークンはパスワードのように働く長い文字列で、プラグインがあなたとしてチャットに書き込めるようにします。Twitch のパスワードをプラグインに渡すことはありません。

1. ブラウザで、チャットに使いたいアカウントで Twitch にログインしてから **https://twitchtokengenerator.com** を開きます(Twitch や本プロジェクトとは無関係の、よく知られたサイトです)。
2. **Bot Chat Token**(チャットボット用)を選びます。独自選択の一覧しかない場合は、権限 **chat:read** と **chat:edit** にチェックを入れます。それ以外は不要です。
3. Twitch で接続するボタンを押します。Twitch の許可画面が出るので、正しいアカウントか確認して **Authorize**(承認)を押します。認証(captcha)が出たら解いてください。
4. サイトに戻ると **Access Token** という長い文字列が表示されます(*Refresh Token* や *Client ID* も表示される場合があります)。**Access Token だけ**をコピーします(コピーボタン、または選択して Ctrl+C)。
5. ゲーム内で `/tw-chat` と入力し、**Config** をクリックします。
6. 「2) O que você quer fazer?」(何をしますか)で **Ler e também enviar mensagens (/tw-chat)**(読み込みと送信)を選びます。
7. 「Seu nome de usuário da Twitch」(Twitch のユーザー名)に、承認したのと同じアカウント名を入力します。
8. 「Token de acesso」(アクセストークン)の欄をクリックし、**Ctrl + V** で貼り付けます。表示は点だけです。
9. **Conectar agora**(今すぐ接続)をクリックします。ステータスが緑色になります: *Conectado a #チャンネル名 como ユーザー名*。
10. 動作確認: プラグインのウィンドウ下の入力欄に文字を入れて Enter、またはゲームのチャットで `/tw-chat こんにちは` と入力します。

### 安全に保管する

- トークンを他人に見せないでください。トークンが見える状態の Config 画面のスクリーンショットも公開しないでください。
- 漏れた場合は **https://www.twitch.tv/settings/connections** を開き、該当アプリ(トークン生成サイト)を見つけて **Disconnect**(切断)を押し、新しいトークンを作り直します。
- トークンは `%APPDATA%\XIVLauncher\pluginConfigs\TwitchWorld.json` に平文で保存されます。このファイルを共有しないでください。

### うまくいかない場合

**ステータスに「Login authentication failed」と出る、またはメッセージが送れない**  
トークンが途中までしかコピーされていない、別のアカウントのもの、または期限切れです。新しく作り直して貼り付けてください。ユーザー名は承認したアカウントと同じである必要があります。

**空白や変な文字が入ってしまう**  
トークン全体を選んでコピーし直し、空の欄に貼り付けてください。手入力はしないでください。

**トークン生成サイトが開かない**  
広告ブロックを切るか、別のブラウザを試してください。サイトの見た目は変わることがあります。チャットボット用 / *Bot Chat Token* の項目を探してください。

**読めるのに送れない**  
「Ler e também enviar mensagens」を選んでいるか、ユーザー名とトークンの両方が入力されているか確認してください。

## よくある問題(リンクでのインストール)

**All Plugins に「Twitch World」が表示されない**  
アドレスが最後まで貼り付けられているか、チェックボックスがオンか確認してください(パートA の手順 5〜7)。**Save and Close** を押してから `/xlplugins` を開き直します。解決しない場合はゲームを再起動してください。

**アドレスが「404」になる、または Dalamud がリポジトリのエラーを表示する**  
プロジェクトの公開がまだ完了していない(最初のビルドに数分かかります)か、プロジェクトが非公開の可能性があります。しばらくして再試行するか、Issue を作成してください。

**「Twitch World」が 2 つ表示される、またはオンにならない**  
古い `.exe` 版が*開発用プラグイン*として残っています。**ステップ 0** を行い、ゲームを再起動してからもう一度インストールしてください。

**アイコンが「?」になる**  
プラグインをオフ→オンにするか、ゲームを再起動してください。

**ゲームのパッチ後に動かなくなった**  
パッチ後は Dalamud が更新されます。プラグインの更新(`/xlplugins` の *Updates*)をお待ちください。直らない場合は GitHub で Issue を作成してください。

**その他**  
この GitHub プロジェクトで Issue を作成し、どの手順で失敗したか書いてください。Twitch トークンは絶対に載せないでください。

## 更新・設定の削除・アンインストール

- **更新:** 自動です。新しいバージョンが出たら `/xlplugins` → **Installed Plugins** → **Update**。
- **設定の削除**(チャンネル、ユーザー名、トークン): ゲームを終了して `%APPDATA%\XIVLauncher\pluginConfigs\TwitchWorld.json` を削除します(エクスプローラーのアドレス欄に貼り付けて開けます)。
- **アンインストール:** `/xlplugins` → **Installed Plugins** → Twitch World → **Delete**。その後 `/xlsettings` → Experimental → Custom Plugin Repositories のアドレスを削除(ゴミ箱)→ Save and Close。
- トークンを使った場合は、Twitch のサイト(設定 → 接続)でアプリのアクセスを取り消してください。

## Twitch の通知と音

バージョン 1.3.0 から、**チャンネル通知**(レイド、サブスク、ギフト、ビッツ、ポイント交換、お知らせ、初参加)も `[RAID]` のようなタグ付きで色付き表示されます。

- **音**:通知とボットのメッセージ(ボット一覧は設定で変更可)のみ。通常のチャットでは鳴りません。
- **音を消す**:Twitch World ウィンドウの **Som: ligado** を押す(**Som: desligado** になります)か、設定 > Alertas da Twitch のチェックを外します。**Testar som** で 1 回再生。
- **制限**:StreamElements/Streamlabs の投げ銭やフォロー通知は、ボットがチャットに書いた場合のみ表示されます(ボットのメッセージ扱い)。
