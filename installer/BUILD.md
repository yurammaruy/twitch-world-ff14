# Building the installer (maintainers)

The installer is a Go program that embeds the plugin source, icons and guides, and compiles the plugin on the user's PC.

```bash
cd installer
mkdir -p payload
cp -r ../plugin payload/Source
cp -r ../assets/icons payload/Icons
mkdir payload/Docs
# guides: UTF-8 with BOM and CRLF line endings (so Windows Notepad shows them correctly)
for l in EN PT JA DE FR; do python3 -c "import sys;t=open('../docs/GUIDE.$l.txt',encoding='utf-8').read().replace('\n','\r\n');open('payload/Docs/README_$l.txt','w',encoding='utf-8-sig',newline='').write(t)"; done
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o TwitchWorldFF14-Setup.exe .
sha256sum TwitchWorldFF14-Setup.exe
```

`icon_windows_amd64.syso` holds the .exe icon and manifest (generated by `tools/make_syso.py` from `assets/icons/TwitchWorld.ico`).
Plugin target: Dalamud API 15 (`Dalamud.NET.Sdk 15.0.0`, `net10.0-windows`).
